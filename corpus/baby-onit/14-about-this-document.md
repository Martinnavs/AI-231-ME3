# baby-onit: about this document

This corpus is the teaching document "baby-onit, Explained", a narrative for the baby_onit.py codebase, an agent harness distilled from onit. The code lives in the repository github.com/sibyl-oracles/baby-onit. The document was generated from baby_onit.py, sections S0 to S9.

The sections of the baby-onit document, in order: why a baby version exists; the big picture; one config dict (S1); secrets (S2); one chat call, many servers (S3); the system prompt is the constitution (S4); tools (S5); registry and dispatch (S6); the agent loop (S7); session memory (S7.5); the text UI (S8); doctor (S8.9); setup (S9); and from toy to real.

baby-onit is about 1,200 lines in one file. onit is roughly 60,000 lines across 104 files.

The document says the baby-onit harness ships eight tools, but its table lists nine: web_search, fetch_content, bash, write_file, read_file, edit_file, local_search, search_document, and grep.
