## 2. How to run the checks

- Gate replay (free): `.venv/bin/python scripts/addressee_replay.py`.
- Delegate doctor (free, hits only github.com and huggingface.co): `make doctor-tools` (`--offline` skips the network checks). Run it on the Pi too with the owner's go.
- Chain evaluation, no spend: `.venv/bin/python scripts/chain_eval.py --dry`; list: `pipeline/.venv/bin/python scripts/chain_eval.py --list`.
- Chain evaluation, live (Gemini, Tavily, Haiku via OpenRouter; about $0.01 per scenario measured, the printed estimate is $0.02): `pipeline/.venv/bin/python scripts/chain_eval.py --max-usd 0.19 --seed N [--only IDS] [--seeds K]`. The spend ledger is `out/chain_eval/ledger.json` (shared across runs; move it aside for a fresh cap). Traces and the scratch workspaces are in `out/chain_eval/<run>/` (git-ignored).
- Tests: `.venv/bin/python -m pytest tests -q --ignore=tests/doc_chat/test_flow.py` (root) and `cd pipeline && .venv/bin/python -m pytest tests -q`. Never `uv run` in the repo (it repoints the editable installs).
