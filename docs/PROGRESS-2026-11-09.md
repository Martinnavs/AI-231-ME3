## 4. Evaluation Hardening & Critique Follow-Ups (Commit `fafc356`)

Following rigorous evaluation critique, 4 targeted improvements were implemented and tested:

1. **Pre-injection Model Verification in `delegate_task_has_facts_or_url`**:
   - Predicate now inspects `call.get("raw_task")` (the model's pre-injection task), stripping any injected code suffixes.
   - Evaluates whether the model itself transferred factual details, research entities, URLs, or explicit fact keywords from prior conversation turns.
2. **Stray `apps/` Output Prevention (`no_stray_apps`)**:
   - Added predicate `no_stray_apps` asserting that non-playable deliverables (`md`, `py`, `none`) create no files under `workspace/apps/`.
   - Updated `system_agent.txt`, `subagent.py`, and `agent_tools.py` to prohibit and strip unrequested `apps/` generation for markdown, scripts, and tables.
3. **Honest Labeling of Injected Conversation Notes**:
   - Relabeled injected facts from `"Verified facts from conversation:"` to `"Notes from the conversation (unchecked):"`, eliminating false authority stamps on unverified third-party claims.
4. **Lookup Deduplication Hang Prevention**:
   - Wrapped `_lookup_future` in `asyncio.wait_for(..., timeout=10.0)` and added `try...finally` resolution to prevent parallel lookups from hanging indefinitely if the primary call fails or is cancelled.
5. **Subagent Source Prompt on Lint Retry (Commit `90c242a`)**:
   - Updated `LINT_RETRY` prompt to remind subagent to summarize deliverable and name its sources when recovering from lint errors.

## 6. Evaluation Predicate & Source Hygiene Tightening

To eliminate predicate false-positives and enforce strict source provenance:

1. **Tightened `delegate_task_has_facts_or_url`**:
   - Strips programmatic injection markers and inspects the model's pre-injection `raw_task`.
   - Removed loose generic keywords (`details`, `features`, `differences`, `history`, `facts`, `verified`) and conversational reply 2-shared-words fallback.
   - Requires grounded extraction: a URL, `/sandbox/scratch/NOTES.md`, a grounded date/year/number/version from the lookup findings in the scratchpad, or technical identifiers/dimensions.
   - Tasks relying on ungrounded memory recall (such as Oxford's "Boat Race, Eights Week, or Encaenia" with no dates or researched facts) now correctly fail.
2. **Strict Source Hygiene in Subagent and Evaluation**:
   - Subagent `SYSTEM` prompt explicitly forbids bare domains (no path) and unused source entries.
   - `subagent.py`'s `check_sources()` flags bare domains (`bare domain <url>`) and unused sources (`unused source <url>`), automatically triggering retry.
   - `scripts/chain_eval.py`'s `deliverable_sources` predicate enforces `urlsplit(u).path` and rejects facts matching `\b(?:not used|unused|did not use|unreferenced)\b`.
3. **Aligned `no_stray_apps` Scope**:
   - Strictly applied to non-playable deliverables (`release_cheatsheet`, `rate_script`, `product_table`).
   - Removed from non-building follow-up scenarios (`pronoun_followup`).

## 8. Architectural Audit & Simplification Roadmap

Following the 8/8 evaluation pass, an architectural review audited the harness for overengineering against the professor's OnIt-parity criterion. Full analysis and 5-phase lean roadmap are documented in [`docs/CHAIN-SIMPLIFICATION-AUDIT.md`](CHAIN-SIMPLIFICATION-AUDIT.md):
- **Core (~65%)**: Concurrency deduplication with timeout, sandbox context bridging, deliverable isolation, and strict source path validation are essential and right-sized.
- **Accidental Complexity (~35%)**: Three overlapping memory stores, task string plumbing, front-agent prompt bloat (+31%), stacked subagent gate loops, and the 10-minute blanket router skip.
- **Lean OnIt Parity**: baby-onit's single general-purpose sandbox loop (`bash`, `read_file`, `write_file`, `edit_file`, `git`) already handles OnIt flagship tasks 2 (build web app) and 3 (security audit) without complex specialized scaffolding. Flagship task 1 requires generalizing `local_search` to arbitrary folders.
