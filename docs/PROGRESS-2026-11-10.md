## 1. P2: the Case F chain protocol moved out of the base prompt

H8 measured the cost, never the condition: the system prompt rides every Gemini request. The audit's
Phase 2 (`docs/CHAIN-SIMPLIFICATION-AUDIT.md`) said to move the Case F multi-step rules into a block
injected when the router escalates or a chain is active. Done, with one honest correction to the
audit's numbers:

- The base prompt is **6 297 chars (1 055 words)**, down from 6 489; the chain protocol is a new
  block, `pipeline/config/eval/system_agent_case_f.txt` (719 chars, 114 words). The audit's "about
  1 560 characters" counted all of Case F; half of it is the delegate mechanics that a *cold* build
  turn needs before any chain exists, so it stays. Sentence-by-sentence mapping: every rule a first
  turn can need (delegate mechanics, research routing, "ask when unsure", the "me" entry,
  "chain_update has no say") is in the base; the multi-turn sequence (readback,
  `awaiting_fact_approval`, the yes question, `phase building`) is in the block. A test pins both
  sides (`test_no_rule_was_lost_in_the_split`).
- **The gating rule** (`AgentServer.steer`, `agent_server.py`): the block is appended to the turn's
  message (1) while a chain is active — together with the `[ACTIVE TASK]` state, (2) when the router
  declines a turn (non-hedged escalation), (3) when there is no router. In the default **hedged**
  config the Gemini requests start before the router decides, so they carry the base prompt only;
  the protocol joins from the moment a chain is active, which the base's entry rules always start
  (research, build, or "me" all call `chain_update` first). No text heuristic was added — the base
  is cold-complete by design instead, and a heuristic that misses one flagship turn would be a
  silent live regression.
- **The chain eval now mirrors the production rule**: the live runner calls the same `steer()`
  with `case_f=chain.active()`, so a live pass tests the split itself (if the base's cold rules
  were incomplete, a scenario would fail on turn 1).
- Not touched: `system_agent_search.txt` (a different, older Case F for `--builtin-search`).
- Sizing, measured: a non-chain Gemini request is 192 chars (~50 tokens) smaller; a chain turn
  gets the core *and* the block (~+500 chars vs the old single text, buying phase-framed protocol
  at exactly the turns that failed on the sequence, e.g. the 2026-11-10 13:42 stall). In the live
  config most simple turns are answered by the router or lost the hedge race, so the user-visible
  TTFT saving lands on Gemini-won complex turns and the no-router mode; the H8 latency
  measurement (~20 requests, ~$0.02) still has not been run.
- Fixed a pre-existing format violation in `pipeline/tests/test_stall_watchdog.py` (one trailing
  blank line from `acc8d06`) that made `make pipeline-check` red at HEAD before this work.
