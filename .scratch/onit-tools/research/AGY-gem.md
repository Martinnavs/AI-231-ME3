### 4. How to Stretch $7 on Both Platforms

#### A. OpenRouter ($7.00 Credit)
1. **Deposit Fee Overhead**: 
   * *Evidence*: OpenRouter charges **5.5% with a $0.80 minimum** on credit card deposits [source: search snippet, `openrouter.ai`, 2026-10-29, quote: *"5.5% of the order amount, subject to a $0.80 minimum fee"*]. 
   * *Tactic*: Depositing \$7 via card loses \$0.80 immediately (net \$6.20). Use **crypto deposits (5.0% flat, no minimum)** to preserve \$6.65 net, or deposit \$15+ in one transaction to avoid the minimum fee penalty [inference].
2. **Sticky Routing & Prompt Caching**:
   * OpenRouter coordinates implicit caching for DeepSeek and OpenAI, and explicit caching for Claude (`cache_control` headers) [source: search snippet, `openrouter.ai`, 2026-10-29]. Ensure requests reuse identical system prompt prefixes and pass sticky routing parameters to hit warm provider caches, cutting input costs by **up to 90%** [source: search snippet, `openrouter.ai`, 2026-10-29].
3. **Response Caching for Development**:
   * Send header `X-OpenRouter-Cache: true` during prompt engineering and pipeline debugging. Identical calls return cached generations at **zero token cost** [source: search snippet, `openrouter.ai`, 2026-10-29, quote: *"When a cached response hits, OpenRouter returns it instantly with zero tokens billed"*].
4. **Reasoning Effort Truncation**:
   * For DeepSeek-V4.1-Flash and Qwen3.8-27b, set `reasoning_effort` (or provider reasoning limits) to `medium` or `low`. Unchecked `max` reasoning generates thousands of hidden thinking tokens billed at output rates, quadrupling the cost of simple terminal actions [inference].

#### B. Google Gemini API Direct ($7.00 Prepaid Balance)
1. **Billing Tier Qualification & Limits**:
   * Linking a billing account and prepaying \$7 automatically qualifies the project for **Tier 1** (spend cap \$250) [source: search snippet, `ai.google.dev`, 2026-10-29].
   * *Rate Limits*: Tier 1 imposes a spend-based rate limit of **\$10 per 10 minutes** [source: search snippet, `google.com`, 2026-10-29, quote: *"For Tier 1, this spend rate limit is $10 per 10 minutes"*]. Batch enqueued token caps are **3M tokens for 3.8 Flash** and **10M tokens for 3.5 Flash-Lite** [source: search snippet, `google.dev`, 2026-10-29].
   * *CRITICAL Billing Trap*: *"Once billing is enabled and a project moves to a paid tier, all usage becomes billable (there is no longer a hybrid 'free allowance up to a limit' model once you cross over)"* [source: search snippet, `datastudios.org` / `google.dev`, 2026-10-29]. Every single development call is metered.
2. **Context Caching Architecture**:
   * **Implicit Caching**: Automatically applies to `gemini-3.8-flash` and `gemini-3.6-flash` when prompt prefixes exceed **4,096 tokens** [source: search snippet, `google.dev`, 2026-10-29, quote: *"Gemini 4 Argon / Gemini 3.8 Flash / Gemini 3.6 Flash / Gemini 3.1 Pro Preview: 4,096 tokens"*]. It provides an **automatic 90% discount** (\$0.075/M vs \$0.75/M) with **zero storage fees** and a 24-hour TTL [source: search snippet, `google.com`, 2026-10-29].
   * **Explicit Caching**: Supported on 3.5/3.8 (minimum threshold **2,048 tokens**), but incurs an hourly storage charge of **\$0.50 to \$1.00 / 1M tokens / hr** [source: search snippet, `google.dev`, 2026-10-29]. Avoid explicit caching for short test loops; rely strictly on implicit caching.
3. **`thinking_level` Configuration**:
   * *Rule*: Gemini 3 models **deprecate `thinking_budget`**. Passing a numeric `thinking_budget` causes `400: INVALID_ARGUMENT` [source: search snippet, `google.com`, 2026-10-29, quote: *"Setting thinking_budget on Gemini 3 and later models results in a 400: INVALID_ARGUMENT error"*].
   * *Configuration*: Use `types.ThinkingConfig(thinking_level=types.ThinkingLevel.LOW)` for Task 1 (web) and Task 3 (terminal commands) to slash TTFT and avoid paying output rates for verbose reasoning scratchpads [source: search snippet, `google.dev`, 2026-10-29]. Reserve `HIGH` only for Task 2 (math verification).
4. **Batch API for Evals**:
   * For the 13-model benchmark runs, submit asynchronous batch requests via `client.batches.create()`. Google grants an automatic **50% discount** on standard token prices (\$0.375 in / \$1.875 out for 3.8 Flash; \$0.15 in / \$1.25 out for 3.5 Flash-Lite) [source: search snippet, `spendline.ai` / `ai.google.dev`, 2026-10-29].

  * Google Cloud Billing / AI Studio deposits carry no credit card transaction fee (a \$7.00 charge gives \$7.00 API balance).
