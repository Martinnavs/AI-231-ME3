### 4. How to Keep $7 Stretching on OpenRouter & Gemini API Direct

#### A. OpenRouter ($7 Credit Allocation)
1. **Account Fees & Real Balance**:
   - OpenRouter imposes a **5.5% platform fee** on standard credit purchases [source: apimart.ai via search snippet, 2026]. Depositing $7 nets **$6.635** in usable inference credit. Never top up with small frequent payments.
2. **Provider Routing & Filtering**:
   - Use the `provider` configuration object in the API request:
     - Set `order`: Route to low-cost providers like `DeepInfra`, `Chutes`, or `Together` first.
     - Set `quantizations: ["fp8"]`: FP8 quantized endpoints reduce token costs by 25–40% over unquantized BF16 while preserving tool precision [inference].
3. **Prompt Caching & Sticky Sessions**:
   - Cache reads receive a **50% to 90% discount** (0.1x to 0.5x of base input) [source: openrouter.ai via search snippet, 2026].
   - OpenRouter implements automated *provider sticky routing* for up to 10 minutes [source: openrouter.ai via search snippet, 2026]. Pass a persistent `session_id` to ensure multi-turn agent turns remain pinned to the identical provider instance to guarantee cache hits.
4. **Reasoning Effort Throttling**:
   - Reasoning tokens count as output tokens ($0.50–$1.40/1M). "The Hidden Cost Trap: Models that aggressively burn reasoning tokens can dramatically multiply your total bill per task" [source: ramadigital.id via search snippet, 2026]. For `gpt-6-luna`, set `reasoning_effort: "low"`; for `qwen3.8-27b`, set `reasoning: {effort: "low"}` to stop multi-thousand token chain-of-thought inflation on basic shell commands.
5. **Free Tiers for Development**:
   - Develop and unit-test the agent harness using OpenRouter's `:free` models (50 free requests/day) [source: openrouter.ai via search snippet, 2026] before spending paid credits on evaluation sweeps.

#### B. Gemini API Direct ($7 Separate Credit Allocation)
1. **Isolated Credit Strategy**:
   - The separate $7 Gemini credit does **not** compete with OpenRouter credits. Dedicate this entire balance to Google models (`gemini-3.8-flash` or `gemini-3.5-flash-lite`), leaving OpenRouter credits exclusively for DeepSeek, Haiku, MiMo, and Qwen.
2. **Batch API (50% Off Development Sweeps)**:
   - "Batch API requests are billed at a 50% cost reduction compared to standard synchronous interactive API rates" ($0.375 in / $1.875 out promo) [source: google.dev via search snippet, 2026].
   - Run offline benchmarking (Task 1, 2, and 3 test suites) via the Batch API. This immediately doubles the evaluation volume from ~115 runs to ~230 runs.
3. **Context Caching Mechanics**:
   - Implicit caching automatically activates on prompts over **4,096 tokens**, discounting cache reads by **90%** ($0.075/1M vs. $0.75/1M) [source: eesel.ai / google.dev via search snippet, 2026].
   - Avoid long-lived *explicit* caches: explicit caches incur a storage fee of **$0.50 per 1M tokens/hour** [source: google.com via search snippet, 2026], which can wipe out token savings if the voice agent is idle between user sessions.
4. **Thinking Budget Clamping**:
   - Gemini 3.8 Flash defaults to adaptive thinking. Use `thinking_config: {thinking_budget: 1024}` on Task 1 and Task 3 to limit CoT tokens to ~1,000 per turn, preventing output token bloat while keeping high task accuracy.
