## 4) Stretching the $7 budgets

**OpenRouter**

- It says inference is billed at provider list price with no markup; its Standard plan adds a **5.5% credit-purchase fee**. The current pricing page says the card fee has an **$0.80 minimum**, so a small top-up can pay a larger percentage than 5.5%. [source: https://openrouter.ai/pricing, retrieved 2026-10-29, “5.5% on Standard”] [source: https://openrouter.ai/blog/simplifying-our-platform-fee, updated 2026-06-11, “minimum fee of $0.80”]
- For repeated agent turns, keep the system prompt and tool schemas stable and use a stable `session_id`; OpenRouter documents provider-dependent cache reads, and recommends checking `cached_tokens` to confirm hits. [source: https://openrouter.ai/blog/tutorials/prompt-caching-sticky-routing, updated 2026-09-24, “A cache read costs 0.1x to 0.5x”]
- Use its `Floor` route when cost is the priority, then verify quality; use `Exacto` when tool-calling accuracy matters. OpenRouter says these are routing modes, not model-level guarantees. [source: https://openrouter.ai/google/gemini-3.1-flash-lite/api, retrieved 2026-10-29, “Exacto [is] highest tool-calling accuracy”]
- OpenRouter lists free models, but they are limited to **20 requests/minute and 50/day**; the daily allowance rises after at least $10 in credit purchases, above this $7 budget. [source: https://openrouter.ai/pricing, retrieved 2026-10-29, “20 requests per minute and 50 per day”]
- Gemini through OpenRouter may cost the same as Google’s provider rate rather than a markup; the live 3.8 page shows a temporary **50% off** rate, but cache rates and provider performance differ. [source: https://openrouter.ai/google/gemini-3.8-flash/providers, retrieved 2026-10-29, “50% off”]

**Gemini API direct**

- Start with the free tier for eligible models, but check the actual project quotas in AI Studio; Google does not publish a guaranteed fixed free quota for all accounts.
- For non-urgent offline work, Batch is half of standard pricing for relevant models; Flex is also discounted for the cited Gemini 3 Flash models. Batch is asynchronous, so it is unsuitable for the user-facing voice response. [source: https://ai.google.dev/gemini-api/docs/optimization, retrieved 2026-10-29, “Batch API … at 50% of the standard cost”]
- Use `minimal` or `low` for simpler jobs, and reserve `medium`/`high` for coding, long tool chains, and harder math. That is a tuning recommendation; Google does not publish an exact token or latency multiplier by level.
- Keep shared prompt material at the beginning and reuse it quickly to improve implicit-cache hits. Google’s cache documentation recommends this and exposes cached-token counts in usage. [source: https://ai.google.dev/gemini-api/docs/caching, updated 2026-10-13, “large and common contents at the beginning”]
- A prepaid $7 balance does not itself specify request limits. Direct Gemini quotas are project and tier based; Tier 1 has a $10/10-minute spend rate limit. The source does not confirm a universal prepaid hard-stop at the balance amount. [source: https://ai.google.dev/gemini-api/docs/rate-limits, retrieved 2026-10-29, “applied per project, not per API key”]
